# Fullstack Quality Pack

A battle-tested quality and reliability bundle for modern TypeScript and fullstack engineering teams.

## Included Components
- 🧠 **Skills**:
  - `skills/typescript/typescript-strict-mode` — Strict types, narrowing, and discriminated unions.
  - `skills/testing/test-coverage-guidance` — Unit/integration/E2E test pyramid strategy.
  - `skills/devops/code-review-checklist` — Structured BLOCKER/MAJOR/MINOR PR reviews.
- 🔌 **MCPs**:
  - `mcps/quality/sentry` — Error diagnostics and telemetry.
- 🤖 **Subagents**:
  - `agents/code-reviewer` — Automated pull request & architectural auditor.
- 📜 **Rules**:
  - `rules/typescript-strict-guardrails.md` — Zero-any type policies.
  - `rules/clean-architecture-boundaries.md` — Layer isolation guidelines.
