# Production Launch Pack

An end-to-end launch verification suite designed to take web apps from development to rock-solid production deployment.

## Included Components
- 🧠 **Skills**:
  - `skills/web/production-web-app-launch` — Production readiness gap audit (SEO, a11y, mobile).
  - `skills/web/web-trust-and-compliance` — Essential trust anchors, policies, and pricing disclosures.
  - `skills/web/nextjs-performance` — Bundle optimization and Core Web Vitals.
- 🔌 **MCPs**:
  - `mcps/devops/cloudflare` — DNS, edge workers, and SSL management.
  - `mcps/browser/chrome-devtools` — Browser automation, performance tracing, and visual auditing.
- 🤖 **Subagents**:
  - `agents/qa-engineer` — Automated regression and edge-case testing.
- 📜 **Rules**:
  - `rules/token-efficiency.md` — Fast, focused execution directives.
