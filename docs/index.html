🔌 How to Use MCP Servers & CLIs

The Model Context Protocol (MCP) connects your AI coding agent directly to live databases, web browsers, API endpoints, and cloud infrastructure.

⚡ 1. Direct Terminal & CLI Execution

Test or run any MCP server on demand with no manual installation:

# Node.js MCP Servers (Node 18+)
npx -y @modelcontextprotocol/server-github
npx -y chrome-devtools-mcp

# Python MCP Servers via uvx
uvx mcp-server-fetch
uvx mcp-server-sentry --auth-token <YOUR_TOKEN>

🛠️ 2. Agent Configuration Presets

Click 📋 Config on any MCP card to copy the JSON snippet, then paste it into your agent's config:

// Antigravity IDE: .agents/mcp_config.json
// Claude Desktop: claude_desktop_config.json
// Cursor: Settings → Features → MCP
{
  "mcpServers": {
    "chrome-devtools": {
      "command": "npx",
      "args": ["-y", "chrome-devtools-mcp"]
    },
    "postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres", "postgresql://user:pass@localhost:5432/mydb"]
    }
  }
}
